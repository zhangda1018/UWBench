Your goal is to provide detailed descriptive text for the image, locate the object for all referring sentences, and answer all visual questions.

- The input includes referring sentences that describe specific objects in the image, and questions about the scene that need to be answered.

Your tasks:

1. Underwater Image Description
   - Create a detailed caption for the provided underwater image that describes the scene comprehensively. Start with an overview that reflects underwater context (e.g., substrate type such as sand, rock, coral; presence of seagrass or algae; clarity/turbidity; artificial structures like ropes, nets, pipelines, wreck fragments if clearly visible).
   - Summarize the scene in 3–7 sentences. Include counts of prominent objects where appropriate.
   - Describe only clear, visually verifiable features. Avoid uncertain or unprovided details such as exact depth, water temperature, camera model, GPS coordinates, or time of day.
   - Use attributes such as texture/patterns (spotted, striped), overall shape (elongated, rounded, branching), relative size, and relative/absolute position (left/right/top/bottom/center). Avoid cardinal directions (north/south) and object-facing directions.
   - Do not hallucinate biological traits (age, sex, behavior) unless they are clearly visible and certain. Do not claim motion status (e.g., swimming, moving) if not obvious.

2. Object Localization from Referring Sentences
   - For each referring sentence provided in the input, identify and locate the referred object in the image.
   - Return the bounding box coordinates in the format [x1, y1, x2, y2], where:
     1) x1 and y1 represent the x and y coordinates of the upper-left corner, respectively
     2) x2 and y2 represent the x and y coordinates of the lower-right corner, respectively
   - Because the resolution of each image varies, all coordinates must be normalized to the range [0.000, 1.000] and rounded to three decimal places. The top-left corner of the image is (0.000, 0.000), and the bottom-right corner is (1.000, 1.000).
   - Also provide obj_corner in the format [x1, y1, x2, y1, x2, y2, x1, y2] with the same normalization.
   - Carefully analyze each referring sentence to identify the correct object. Use visual features mentioned in the sentence (position, size, shape, texture, color, adjacency to other structures) to accurately locate the object.
   - Ensure that the bounding box tightly encompasses the referred object without excessive padding.
   - Do not modify the referring sentence text; echo it exactly as provided in the input.

3. Answer Visual Questions
   - For each question provided in the input, provide a concise answer using a single word or phrase based on the image content.
   - Answer only what is clearly visible and verifiable in the image. If an answer is uncertain or not visible, state "unknown" or "unclear".
   - For Yes/No questions, answer "Yes" or "No".
   - For quantity questions, provide numerals (e.g., "3").
   - For category/color/shape/position questions, provide concise descriptive terms.
   - Use category names exactly as provided in the input where appropriate.
   - Do not speculate about invisible attributes such as exact depth, temperature, capture device, or time of day.
